# نهضة الملائكة 😇 — v2

تطبيق ويب PWA عربي (RTL) لإدارة أطفال الخدمة: تسجيل بالكروت (QR)، حضور، نقاط، إحصائيات، صلاحيات — **بتحديث لحظي كامل (Realtime)**.

## نظرة عامة
- **الاسم**: نهضة الملائكة (Nahdat al-Malaika)
- **التقنيات**: Next.js 14 (App Router) + TypeScript + Tailwind CSS + Supabase (Auth / Postgres / Storage / **Realtime**)
- **الاستضافة**: جاهز للنشر على Vercel
- **GitHub**: https://github.com/stmaryluxorprim-hash/Nahdet-El-Malayka (فرع `redesign-v2`)

## 🎨 تحسينات الواجهة
- **أيقونات احترافية**: استبدال الإيموجي بأيقونات SVG خطية موحّدة (مكوّن `src/components/Icon.tsx`) في القائمة الجانبية وشريط التنقل السفلي والهيدر.
- **صفحة طباعة الكروت**: تخطيط دقيق لورق A4 (شبكة 2×5 = 10 كروت) مع أنماط طباعة مخصصة (`@media print`) تُخفي الواجهة وتضبط الهوامش.

## 🗄️ قاعدة البيانات (Supabase)
نفّذ الملفات بالترتيب في SQL Editor:
1. **`supabase/schema.sql`** — الأساس: أدوار وصلاحيات، profiles، classes، children، attendance، point_transactions، app_settings، RLS، bucket للصور
2. **`supabase/migration_v2.sql`** — إضافات v2: عمود `username`، جدول `user_permissions`، تحديث `has_permission` (دور **أو** فردية)، دالة `get_child_portal` (بوابة الطفل)، تفعيل Realtime publication لكل الجداول
3. **`supabase/migration_v3_day_schedule.sql`** — تنظيم اليوم: جداول `day_tasks` و `day_assignments`
4. **`supabase/migration_v4_phone_delete.sql`** — رقم تليفون فريد إجباري + دالة `admin_delete_user` (حذف الخادم نهائياً)
5. **`supabase/migration_v5_fix_user_delete.sql`** — 🔧 **إصلاح حذف الخادم**: تحويل قيود FK (children.created_by / attendance.recorded_by / point_transactions.created_by / activity_log.user_id) إلى `ON DELETE SET NULL` + تحسين `admin_delete_user` — بدونه يفشل الحذف من التطبيق **ومن لوحة Supabase** لأي خادم سجّل أي بيانات
6. **`supabase/migration_v6_schedule_supervisor.sql`** — 🗓️ **صلاحيات تنظيم اليوم**: المدير **والمشرف** فقط يضيفون/يزيلون خدام الوظائف (`day_assignments`) — الخادم يشاهد التقسيمة فقط. الوظائف نفسها (`day_tasks`) تبقى للمدير فقط
7. **`supabase/migration_v7_card_profiles.sql`** — 🪪 **بروفايلات طباعة الكروت**: جدول `card_profiles` (اسم + prefix + إعدادات التصميم JSON)، جدول `card_print_counters` (آخر رقم مطبوع لكل prefix)، ودالة `record_cards_printed` لتسجيل الطباعة (تحتفظ دائماً بالأكبر)

> ⚠️ **مهم**: في Supabase → Authentication → Providers → Email: **عطّل "Confirm email"** — الدخول باسم المستخدم يستخدم بريداً داخلياً (`<username>@nahdat-app.local`).

- **أول مستخدم يسجّل يصبح أدمن تلقائياً** ويُعتمد فوراً.

## 🧩 نماذج البيانات
- `profiles`: id, full_name, **username**, role_id, status (pending/approved/rejected)
- `user_permissions`: user_id, permission_id, granted_by — صلاحيات فردية فوق صلاحيات الدور
- `children`: code (QR), name, phone, gender, class_id, photo_url, total_points
- `attendance`: child_id + date (فريد), status, recorded_by
- `point_transactions`: child_id, points (+/-), category, reason — تُحدِّث total_points تلقائياً

## 🚀 التشغيل محلياً
```bash
npm install
cp .env.example .env.local   # ضع NEXT_PUBLIC_SUPABASE_URL و NEXT_PUBLIC_SUPABASE_ANON_KEY
npm run dev
```

## 📱 دليل الاستخدام السريع
1. سجّل أول حساب → يصبح أدمن تلقائياً
2. الأدمن يوافق على باقي الحسابات من الإعدادات → المستخدمون، ويمنح الأدوار/الصلاحيات الفردية
3. أضف الأطفال من تبويب الأطفال (+ → مسح كارت QR → البيانات + الصورة)
4. سجّل الحضور والنقاط من الماسح (اختر الوضع + النقاط) أو من أزرار الوظائف في تبويب الأطفال
5. أعطِ الطفل كارته — يدخل به من صفحة الدخول ليرى نقاطه وحضوره لحظياً
